Screens

Drag items on the stage, resize from the corners, nudge with the arrow keys (Shift = 10 px). Ctrl+D duplicates, Delete removes.

Settings menu order

Drag rows (or use the arrows) to reorder them or move them to another group; drag a group's handle to move the whole group. Rename a group in its title. The eye hides a row from the list. Saved with the layouts and in the exported JSON (settingsMenu). Pico2Maple rows only show when that adapter is connected; the Internet screen's own rows are not listed.
